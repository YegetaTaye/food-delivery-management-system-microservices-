┌─────────────────────────────────────────────────────────────────────────────┐
│                    FLOW 1: Manual Payment (REST API)                         │
└─────────────────────────────────────────────────────────────────────────────┘

Client
  │
  │ POST /payments
  │ {order_id, amount, method}
  ▼
FastAPI
  │
  │ Validate request
  ▼
Payment API
  │
  │ Simulate payment (80% success)
  ▼
Database
  │
  │ INSERT payment record
  ▼
RabbitMQ
  │
  │ Publish payment.success/failed
  ▼
Response to Client
  │
  │ {payment_id, status, ...}
  ▼
Client receives payment result


┌─────────────────────────────────────────────────────────────────────────────┐
│                FLOW 2: Automatic Payment (Event-Driven)                      │
└─────────────────────────────────────────────────────────────────────────────┘

Order Service
  │
  │ Publish order.created event
  ▼
RabbitMQ (food_delivery exchange)
  │
  │ Route to payment_queue
  ▼
Payment Consumer
  │
  │ Receive order.created
  │ {order_id, total_amount, ...}
  ▼
Payment Processing
  │
  │ Simulate payment (80% success)
  ▼
Database
  │
  │ INSERT payment record
  ▼
RabbitMQ
  │
  │ Publish payment.success/failed
  │ {payment_id, order_id, status, amount}
  ▼
Other Services
  │
  │ Consume payment events
  ▼
Update order status, notify customer, etc.
